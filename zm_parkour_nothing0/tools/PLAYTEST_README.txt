zm_parkour_nothing0 - playtest build (not published; please don't share it on)
===========================================================================

You need
--------
- Call of Duty: Black Ops III on PC (Steam). The base game is enough: everything the map uses is inside these files.
- About 14 GB of free disk space while installing (the zip is ~6.5 GB; the installed map is ~6.5 GB, and you can delete the zip afterwards).

Install
-------
1. Find your Black Ops III folder. In Steam: right-click Black Ops III > Manage > Browse local files.
   Usually: C:\Program Files (x86)\Steam\steamapps\common\Call of Duty Black Ops III
2. If there is no "usermaps" folder in there, create one (exact name: usermaps).
3. Extract this zip INTO the usermaps folder. You should end up with:
     ...\Call of Duty Black Ops III\usermaps\zm_parkour_nothing0\zone\zm_parkour_nothing0.ff
   (If you see ...\usermaps\zm_parkour_nothing0\zm_parkour_nothing0\zone\..., it was extracted one folder too deep - move it up.)

Play
----
1. Start Black Ops III and go to Zombies.
2. Solo (or Private Match to play together - everyone in the lobby needs the same files installed).
3. Change the map and pick zm_parkour_nothing0 from the custom maps list, then start.
   If it isn't listed, the folder path in step 3 of Install is wrong.

How the map starts
------------------
- Round 1 does NOT start until someone clears the line of barrels at the north edge of the spawn deck (it's free).
- If you fall, shoot one of the green circles under the paths (from below) to get teleported back.
- The red machine at spawn is Mule Lick, a custom perk ($500): you lose a gun slot, but the next perk you get is never lost, even if you go down.

Uninstall
---------
Delete the usermaps\zm_parkour_nothing0 folder.
