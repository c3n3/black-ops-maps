# Endless spawning

- I saw an online post about setting up a map to do endless spawning, I want you to implement that for this project:

```
It's actually pretty simple. What I did for Maison and Maison Ext, and you can put this anywhere in your script (I'd recommend making a new function and threading it from your main to prevent getting stuck at this because it's a loop) is this:

zombie_utility::set_zombie_var( "zombie_spawn_delay", 				2.0,	true,	column );

while(1)
{
	wait(15);
	level.zombie_total = 115;
}

Every fifteen seconds, the round's zombie queue changes to 115. The only way to technically pass the round is kill 115 of the queued zombies in 15 seconds, which should be impossible.

This will make the round infinite.

Additionally, if you'd like to lower the delay between zombie spawns, modify the 2.0 to something smaller. This can also go anywhere in your script. This is the base value of the spawn delay- it decreases based on the round number and will continue to decrease if you continue to pass rounds.

Edit: I missed the time between rounds bit.
	zombie_utility::set_zombie_var( "zombie_between_round_time", 		10 );
```

# Q/A

- Q: What base zombie spawn delay should be used? (The post uses 2.0 seconds; smaller = faster spawns.)
  - A: 2.0 (as posted)
- Q: Keep the refill loop as posted: every 15 seconds, reset the zombie queue (level.zombie_total) to 115?
  - A: Yes, 15s / 115
- Q: Between-round time: the post sets it to 10 seconds. Since the round never ends, this mostly only affects the start of the game. Use 10?
  - A: 10 (as posted)
