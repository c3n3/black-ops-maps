# Candle flicker

- All the lights in the map that are not main_light and that have the flicker cookie should have randomized flicker rates.
- The goal is to make them flicker like a candle, so set the random rates appropriately.
- More lights will be added in the future, so make a script to do this.
- Filter the candles out based on whether they have the "scriptable" flag set to true (ignore those in the script).

# Q/A

- Q: When the tool is run again after adding lights, what should happen to lights it already randomized? Re-roll all, or only new lights?
  - A: Re-roll all
- Q: Where should the tool live, and how will it be run?
  - A: Python in the map folder: zm_parkour_nothing0/tools/randomize_candle_flicker.py, run with uv. It edits map_source/zm/zm_parkour_nothing0.map in place after saving a backup (Radiant closed, or reload the map afterwards).
