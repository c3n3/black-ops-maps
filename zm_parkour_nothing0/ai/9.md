# Mule Lick

- Make a perk called "Mule Lick". Cost 500.
- Effect: -1 gun slot. The next purchased perk is never lost (including Mule Lick) regardless of downs / respawns.
- Mule Lick ties itself to a single perk for the whole game; the effect is irreversible.
- Use all Mule Kick models (duplicate), then apply a red filter; same with the UI icon.
- Place this perk at the spawn of the map.
- If the user has Mule Kick + Mule Lick at the same time, they get the normal 2 guns.

# Q/A

- Q: The Mule Kick model, bottle and icon only exist compiled in the game files (no sources in the mod tools), so they can't be recoloured here. How should Mule Lick look?
  - A: Do the red glow now. For the icon, pull a png of the Mule Kick icon from the internet and run effects on it.
- Q: Which perks count as "the next purchased perk" that gets bound?
  - A: Any perk gained
- Q: Buying Mule Lick with 2 guns drops you to 1 slot. Which gun is taken?
  - A: The one not in hand
- Q: In solo, Quick Revive is normally used up by self-revives. If the bound perk is Quick Revive, what happens?
  - A: Normal solo rules (stays bound, but solo self-revives still consume it)
